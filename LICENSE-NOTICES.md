# Third-Party Reference & License Compliance Notices

This project (**SEO OS AI Workbench**) is a **100% clean-room original implementation**. No proprietary code, branding, assets, or copyleft source files were copied or vendored from any reference project.

## Inspected Reference Projects

1. **SEO OS** (`https://github.com/AgriciDaniel/seo-os`)
   - **Observed License**: GNU Affero General Public License v3.0 (AGPL-3.0).
   - **Compliance Decision**: Because AGPL-3.0 imposes network copyleft obligations on derivative source code, **zero source files, assets, or styles were copied or vendored** from `AgriciDaniel/seo-os`. Only high-level UX concepts (3D spatial office/desk metaphor, central orchestrator, specialist desks, knowledge graph chandelier, OS-style windows, task feed state semantics, and 7 switchable office themes) were used as architectural inspiration.

2. **OpenFuse** (`https://github.com/CopilotKit/openfuse`)
   - **Observed License**: MIT License.
   - **Compliance Decision**: Architectural & UX inspiration only for the isolated Personal Agent path (durable plans, progress controls, browser takeover, inline cards, opt-in terminal/files, goals, monitors, receipts). No source code vendored.

3. **OpenDots** (`https://github.com/CopilotKit/OpenDots`)
   - **Observed License**: MIT License (template source; runtime services have separate terms).
   - **Compliance Decision**: Architectural & UX inspiration only for persistent Business AI Coworkers, Business Spaces with revision history, live computer panels, and human-in-the-loop approval cards. No source code vendored.

4. **OpenBot** (`https://open.bot/` / `CopilotKit/OpenBot`)
   - **Observed License**: Mixed / Dual-licensed (MIT frontend templates + PolyForm Noncommercial / Commercial enterprise backend).
   - **Compliance Decision**: Product-direction reference only for enterprise governance concepts (RBAC, tool allowlists, approval policies, audit trails, SSO/SCIM readiness interfaces, and self-hostable deployment templates). No source code vendored.
